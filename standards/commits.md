# Стандарт: коміти, гілки, PR

Версія: 0.1 · Статус: чернетка

## Повідомлення коміту

Формат [Conventional Commits](https://www.conventionalcommits.org/): тип і scope — англійською
(машинно-читані), опис і тіло — українською.

```
<тип>(<scope>): <опис у наказовому способі, ≤ 72 символи, без крапки>

<тіло: навіщо зміна, що не очевидно з diff; необов'язкове>

<трейлери: AI-Prompt, Co-Authored-By — для комітів ШІ>
```

- Типи: `feat`, `fix`, `docs`, `test`, `refactor`, `build`, `chore`, `ci`.
- Scope: модуль або область — `spec`, `standards`, `adr`, `arch`, `ai`, `hooks`, назва модуля.
- Приймання документа автором: `docs(<scope>): прийняти <документ>`.
- Один логічний крок на коміт: код, його тести й конфіг — разом; несумісні зміни — окремо.

Приклад: `docs(spec): додати spec-fix-01 з уточненнями лаби 1`.

## Гілки

- `main` — лише через merge PR.
- `feature/labN-<slug>` — робота над лабою; `fix/<slug>` — виправлення поза лабою.

## PR

- Один PR на лабу: `feature/labN-<slug>` → `main`.
- Опис: посилання на `spec.md`, `DEFENSE.md` і звіт `make check`.
- Merge — merge-комітом (не squash і не rebase), щоб зберегти історію й трейлери ШІ.
