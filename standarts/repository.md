# Стандарт: чистий репозиторій

Версія: 0.1 · Статус: прийнято

## Не комітиться

- Встановлені залежності (каталоги пакетного менеджера).
- Артефакти збірки, покриття, кеші інструментів, логи.
- Секрети: `.env` та подібні, ключі, токени. Приклад конфігу — лише `*.example`.
- Файли IDE та ОС (`.idea/`, `.vscode/` крім спільних налаштувань, `.DS_Store`, `Thumbs.db`).

Конкретні шляхи — у `.gitignore`; перевірка — C3 (`make hygiene`).

## Дозволені файли без розширення

Будь-який інший файл без розширення валить C3.

| Файл | Навіщо |
|---|---|
| `Makefile` | Єдина точка запуску перевірок |
| `LICENSE` | Ліцензія |
| `.gitignore` | Виключення з репо |
| `.gitattributes` | Нормалізація кінців рядків (LF) |
| `.editorconfig` | Базовий стиль для редакторів |
| hook-скрипти (`pre-commit`, `pre-push`, `commit-msg`) | Лише в каталозі hook-ів, обраному в ADR |

Список розширюється лише зміною цього стандарту (нова версія + журнал змін).
