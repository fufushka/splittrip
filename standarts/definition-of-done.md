# Стандарт: Definition of Done

Версія: 0.2 · Статус: запропоновано

## Коміт готовий, якщо

- [ ] Один логічний крок; повідомлення — за [commits.md](commits.md).
- [ ] Hook-и пройшли без обходу (`--no-verify` заборонено).
- [ ] Коміт ШІ має трейлери `AI-Prompt` і `Co-Authored-By` ([ai-workflow.md](ai-workflow.md)).
- [ ] Нова залежність має однорядкове «навіщо» в README.

## PR готовий, якщо

- [ ] Гілка `feature/labN-<slug>` від `main`, ціль — `main`; одна гілка — одна лаба.
      Виправлення попередньої лаби — окрема гілка й PR.
- [ ] `npm run check` на чистому клоні проходить; вивід збережено в `reports/`.
- [ ] Є рев'ю-коментарі, усі розв'язані (виправлено або обґрунтовано відхилено).
- [ ] Merge — merge-комітом (не squash), щоб зберегти історію й трейлери.

## Лаба готова, якщо

- [ ] `spec.md` ≤ 1 сторінки з критеріями прийняття, закомічена й прийнята автором до
      реалізації ([spec-format.md](spec-format.md)); великі таблиці контракту — у файлі поруч
      (`contract.md`), на який spec посилається.
- [ ] Коміти стандартів, архітектури й ADR — раніше за перший коміт реалізації.
- [ ] Кожне ключове рішення — ADR за [adr-template.md](adr-template.md).
- [ ] Код — через коміти; артефакти запуску в `reports/` разом із командою `npm run …`, що
      їх відтворює.
- [ ] Розбіжності spec ↔ вихід ШІ виправлено зміною spec, критеріїв чи стандарту, а не
      ручним патчем коду; кожна має ланцюжок промпт → фідбек → spec-fix → коміт.
- [ ] Усі промпти лаби збережено дослівно в `ai/labN/`.
- [ ] `DEFENSE.md` — 1 сторінка, **пише автор**, за шаблоном DoD курсу §4:
      1. що я просив у AI (1–2 речення) + `ai/`;
      2. топ-3 розбіжності: що було не так (проти якого пункту spec) · мій слід (промпт /
         фідбек / spec-fix) · коміт виправлення;
      3. ключове рішення — чому (`adr/…`);
      4. перевірка: `npm run <ціль>` → результат, версія `/version` → `<sha>`.
- [ ] Аудит — розділ DEFENSE (топ-3) плюс те, що окремо вимагає умова лаби; повний аудит
      критеріїв — лише якщо його вимагає spec.
- [ ] Репозиторій чистий ([repository.md](repository.md)); історія після пушу не
      переписується ([commits.md](commits.md)).
- [ ] PR змерджено; кореневий README посилається на DEFENSE лаби.
