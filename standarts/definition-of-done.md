# Стандарт: Definition of Done

Версія: 0.1 · Статус: чернетка

## Коміт готовий, якщо

- [ ] Один логічний крок; повідомлення — за [commits.md](commits.md).
- [ ] Hook-и пройшли без обходу (`--no-verify` заборонено).
- [ ] Коміт ШІ має трейлери `AI-Prompt` і `Co-Authored-By` ([ai-workflow.md](ai-workflow.md)).
- [ ] Нова залежність має однорядкове «навіщо» в README.

## PR готовий, якщо

- [ ] Гілка `feature/labN-<slug>`, ціль — `main`.
- [ ] `make check` на чистому клоні проходить; вивід збережено в `reports/`.
- [ ] Є рев'ю-коментарі, усі розв'язані (виправлено або обґрунтовано відхилено).
- [ ] Merge — merge-комітом (не squash), щоб зберегти історію й трейлери.

## Лаба готова, якщо

- [ ] `spec.md` ≤ 1 сторінки з критеріями, закомічена й прийнята автором до реалізації
      ([spec-format.md](spec-format.md)).
- [ ] Коміти стандартів, архітектури й ADR — раніше за перший коміт реалізації.
- [ ] Кожне ключове рішення — ADR за [adr-template.md](adr-template.md).
- [ ] Код — через коміти; артефакти запуску в `reports/` разом із командою `make …`, що
      їх відтворює.
- [ ] `audit.md`: кожен критерій spec і spec-fix — виконано чи ні + доказ; топ-3
      розбіжності / «зрізані кути» ШІ: промпт → фідбек → spec-fix чи зміна стандарту → коміт.
- [ ] Розбіжності виправлено зміною spec, критеріїв чи стандарту, а не ручним патчем коду.
- [ ] Усі промпти лаби збережено дослівно в `ai/labN/`.
- [ ] `DEFENSE.md` ≤ 1 сторінки за шаблоном курсу: що і навіщо; топ-3 розбіжності → коміт;
      ключове рішення → ADR; перевірка `make <ціль>` → результат і версія `/version: <sha>`.
- [ ] Репозиторій чистий ([repository.md](repository.md)).
- [ ] PR змерджено; кореневий README посилається на DEFENSE лаби.
