# Стандарт: перелік перевірок

Версія: 0.1 · Статус: прийнято

Інструменти для кожної перевірки обираються в ADR після вибору стеку; тут зафіксовано,
**що** перевіряється, **коли** і **що блокується**. Команди `make` однакові для будь-якого стеку.

| ID | Перевірка | Що перевіряється | Як запустити | Коли | Блокує |
|---|---|---|---|---|---|
| C1 | Формат | Код і конфіги відповідають форматеру (без змін після його запуску) | `make format-check` (виправити: `make format`) | pre-commit, `make check` | коміт |
| C2 | Лінт | Правила лінтера, 0 помилок | `make lint` | pre-commit, `make check` | коміт |
| C3 | Чистота репо | Немає заборонених файлів і секретів; файли без розширення — лише зі списку ([repository.md](repository.md)) | `make hygiene` | pre-commit, `make check` | коміт |
| C4 | Повідомлення коміту | Формат за [commits.md](commits.md); якщо є трейлер `AI-Prompt`, файл промпту існує | автоматично | commit-msg | коміт |
| C5 | Статичний аналіз | Типи / статичний аналіз, 0 помилок | `make typecheck` | pre-push, `make check` | пуш |
| C6 | Межі модулів | Імпорт лише через публічну точку входу; немає циклів і заборонених напрямів ([architecture.md](../docs/specs/lab1-foundation/architecture.md)) | `make boundaries` | pre-push, `make check` | пуш |
| C7 | Збірка | Проєкт збирається без помилок | `make build` | pre-push, `make check` | пуш |
| C8 | Smoke | Старт, `GET /health`, `GET /version` за spec-fix-01 п. 1 | `make smoke` | pre-push, `make check` | пуш |
| C9 | Слід ШІ | Список комітів для кожного промпту в `ai/` | `make ai-trace` | вручну, перед здачею | — (звіт) |

## Загальні цілі

- `make install` — встановлює залежності й підключає hook-и (крит. 6), без ручних кроків.
- `make check` — C1–C3 і C5–C8 одна за одною; зупиняється на першій помилці з ненульовим
  кодом виходу (крит. 5).

## Правила

- Hook-и лише викликають цілі `make`, щоб локальний запуск і hook давали однаковий результат.
- Обхід hook-ів (`--no-verify`) заборонено; якщо перевірка хибна, її виправляють зміною
  стандарту або конфігу окремим комітом.
- Звіт перевірки — реальний вивід команди в `docs/specs/labN-<slug>/reports/<ID>-<назва>.txt`
  з першим рядком-командою, що його відтворює.
