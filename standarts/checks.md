# Стандарт: перелік перевірок

Версія: 0.4 · Статус: запропоновано

Інструменти для кожної перевірки обираються в ADR після вибору стеку; тут зафіксовано,
**що** перевіряється, **коли** і **що блокується**. Точка запуску — `npm run …` (ADR-0014).

## Загальні цілі

- `npm ci` — встановлює залежності й підключає hook-и (скрипт `prepare`), без ручних кроків.
- `npm run check` — C1–C3, C5–C8 і C11 одна за одною; зупиняється на першій помилці з ненульовим
  кодом виходу (крит. 5).

## Правила

- Hook-и лише викликають `npm run …`, щоб локальний запуск і hook давали однаковий результат.
- Обхід hook-ів (`--no-verify`) заборонено; якщо перевірка хибна, її виправляють зміною
  стандарту або конфігу окремим комітом.
- **Перевірка, що не може впасти, не рахується.** Для кожної з C1–C8 і C11 у `npm run demo` є
  сценарій, де вона відхиляє порушення; без такого сценарію перевірку не вважають готовою.
- **Помилка інструмента = провал.** Скрипт перевірки розрізняє «порушень немає» і «не
  вдалося перевірити»; друге завершується ненульовим кодом, а не «чисто».
- Звіт перевірки — реальний вивід команди в `docs/specs/labN-<slug>/reports/<ID>-<назва>.txt`
  з першим рядком-командою, що його відтворює.
