## 3. Ключове рішення

**Composition root + AsyncLocalStorage** ([ADR-0016](../../adr/0016-composition-root-and-async-context.md)).
Ресурси процесу (пул, репозиторій, Auth) створює `main.ts` і передає у фабрики. `userId` і
`processId` живуть у `context`, а pino `mixin` додає `processId` у кожен лог. Чому так: сервіси
отримують лише бізнес-аргументи, і для цього не треба ні DI-контейнера (awilix), ні нової моделі
програмування (Effect). Явний `ctx` не підходить — це саме те протягування, яке забороняє умова.
Транзакції — тільки в `storage`: `update(tripId, mutate)` з `FOR UPDATE` ([ADR-0018](../../adr/0018-aggregate-update-with-row-lock.md)).
