# 0014. `npm run` як єдина точка запуску перевірок (замінює ADR-0008)

## Контекст і проблема

ADR-0008 обрав Makefile, бо «курс вимагає `make …`». Новий DoD курсу (§5, «Відтворюваність»)
це знімає: «для Node.js достатньо `npm run …`, окремий Makefile не потрібен». Головний
чинник ADR-0008 зник, а ціна лишилась: на Windows `make` треба встановлювати окремо
(spec лаби 2, крит. 13; `ai/lab2/004`).

## Чинники рішення

- Одне джерело правди для команд.
- Нуль ручних кроків встановлення на Windows, macOS і Linux.
- Hook і ручний запуск дають однаковий результат.

## Розглянуті варіанти

- Лише npm scripts, Makefile видалити
- Залишити Makefile поверх npm scripts (ADR-0008)

## Рішення

Обрано «лише npm scripts»: Node вже є вимогою, `npm` є разом із ним, а кожна ціль Makefile і
так була одним рядком `npm run …`.

### Наслідки

- Добре: мінус один інструмент у «Вимогах» README; один файл зі списком команд.
- Добре: hook-и викликають `npm run`, тож локальний запуск і hook збігаються, як і раніше.
- Погано: зміна звичок і документації лаби 1 (README, checks.md) — разом із цим ADR.
- Погано: послідовний ланцюжок `check` пишеться в `package.json` через `&&`, а не
  залежностями цілей make.

### Підтвердження

У корені немає `Makefile`; C3 (`npm run hygiene`) валить його появу (repository.md 0.2);
`npm run check` на чистому клоні проходить.

## Плюси й мінуси варіантів

### Лише npm scripts

- Добре: нічого не встановлювати; звично для Node-розробника.
- Погано: довгі ланцюжки `&&` у JSON читаються гірше за Makefile.

### Makefile поверх npm scripts

- Добре: короткі назви цілей, залежності між цілями.
- Погано: два файли з тим самим переліком; `make` на Windows ставиться вручну; чинника
  «вимога курсу» більше немає.

## Додаткова інформація

Замінює [ADR-0008](0008-makefile-over-npm-scripts.md). Промпт: `ai/lab2/004`.
