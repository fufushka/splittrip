# Інструкції для ШІ-агента (SplitTrip)

Проєкт — навчальний, лаби курсу виконуються з ШІ. Джерело правил — [standarts/](standarts/)
і DoD курсу «з AI». Цей файл — обов'язкові дії агента; деталі — у стандартах, не тут.
Мова документів і повідомлень комітів — українська (тип і scope — англійською).

## Перед будь-якою дією у відповідь на промпт

1. **Зберегти промпт автора дослівно** в `ai/labN/NNN-<slug>.md` (лише текст автора, без
   виправлень друкарських помилок, без відповідей ШІ). Нумерація наскрізна в межах лаби,
   `<slug>` — 2–5 слів англійською. Відповіді автора на уточнювальні питання — теж промпти.
   Якщо не зрозуміло, до якої лаби належить промпт, — запитати.
2. Прочитати spec поточної лаби (`docs/specs/labN-<slug>/spec.md` + усі `spec-fix-NN.md`).
3. Якщо spec неоднозначна, суперечить інструкції автора або потрібне рішення з реальними
   альтернативами (кандидат на ADR) — **зупинитися, перелічити розбіжності й запитати**.
   Не «виправляти» автора на власний розсуд.

## Що агент НЕ робить

- **Не пише `DEFENSE.md`** — його пише автор власноруч (DoD курсу); агент лише рев'юїть.
- **`spec.md` — лише після допиту.** Спершу агент аналізує, знаходить суперечності, ставить
  уточнювальні питання й пропонує варіанти; рішення ухвалює автор (його відповіді — в
  `ai/labN/`). Потім агент пише чернетку spec із посиланнями на ці відповіді, автор
  рев'юїть і приймає окремим комітом. Агент не вигадує вимог, на які автор не відповів, —
  позначає їх як відкриті питання.
- Не змінює прийняті spec, стандарти й ADR — лише пропонує spec-fix, нову версію стандарту
  чи новий ADR; автор приймає окремим комітом.
- Не виправляє розбіжність ручним патчем коду без зміни входу (spec / критерій / стандарт).
- Не пушить, не створює й не мерджить PR без явного прохання автора.
- Не переписує історію, що вже запушена (`--force`, `rebase`, `amend` запушених комітів).
- Не обходить hook-и (`--no-verify`) і не послаблює перевірки.
- Не робить `git add -A` / `git commit -a` — лише явно названі шляхи.

## Коміти агента

- Формат — [standarts/commits.md](standarts/commits.md); один логічний крок на коміт;
  перед комітом — `git diff --cached --stat`.
- Файл промпту комітиться не пізніше за перший коміт, який цей промпт породив.
- Кожен коміт агента закінчується трейлерами:

  ```
  AI-Prompt: ai/labN/NNN-<slug>.md
  Co-Authored-By: Claude <модель> <noreply@anthropic.com>
  ```

- Гілка — `feature/labN-<slug>` від `main`; одна гілка — одна робота. Виправлення
  попередньої лаби — окрема гілка, не в PR поточної.

## Перевірка результату

- Перевіряти зміст кожного файлу проти критеріїв spec, а не лише наявність файлів.
- Розбіжності spec ↔ результат перелічувати явно — це матеріал для топ-3 в DEFENSE автора.
- Команди відтворення — `npm run …` за [standarts/checks.md](standarts/checks.md)
  (Makefile прибирається в лабі 2, ai/lab2/004).
