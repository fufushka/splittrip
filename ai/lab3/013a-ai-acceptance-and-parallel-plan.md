## 2. Docker

Docker зараз не запущено, а потік B (npm test, E2E, інтеграційні на Postgres) без нього не
перевірити. Що робимо з потоком B?

- **Запущу Docker зараз** — Ви запускаєте Docker Desktop, і потік B стартує разом із A та C.
  Агент сам підніме Supabase (npm run db:start).
- **B — пізніше** — Зараз лише A і C (без Docker). B запустимо, коли скажете, що Docker
  працює.
- **B писати без перевірки** — Агент пише код B зараз, а проганяємо його, коли з'явиться
  Docker. До того часу код B неперевірений — це ризик.
